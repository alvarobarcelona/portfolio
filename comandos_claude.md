# Comandos Útiles para Claude Code

Aquí tienes una lista de los comandos y "slash commands" (comandos que empiezan con `/`) más útiles cuando usas la CLI (interfaz de línea de comandos) de Claude:

## Comandos de Terminal
- `claude` : Inicia la sesión interactiva de Claude Code.
- `claude -p "tu mensaje"` : Ejecuta un prompt específico y sale al terminar (útil para scripts o consultas rápidas).
- `claude update` : Actualiza Claude Code a la última versión.
- `claude config` : Muestra o modifica la configuración de Claude.

## Slash Commands (Dentro de la sesión de Claude)
- `/help` : Muestra la lista de comandos disponibles y ayuda.
- `/compact` : Compacta la conversación actual. Esto resume el historial para ahorrar tokens y reducir costos, manteniendo el contexto clave.
- `/cost` : Muestra el costo acumulado y el uso de tokens de la sesión actual.
- `/clear` : Limpia el historial de la conversación actual.
- `/bug` : Permite reportar un problema o bug al equipo de desarrollo.
- `/exit` (o `Ctrl+C`) : Cierra la sesión de Claude Code.

## Atajos y Consejos
- **Flecha Arriba / Abajo** : Navega por el historial de mensajes que has enviado.
- **Tabulador** : Autocompleta rutas de archivos o directorios mientras escribes tu prompt.
